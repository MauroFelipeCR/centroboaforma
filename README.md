# Centro Boa Forma 🏋️‍♂️

Este é um projeto de um site institucional para uma academia, focado em apresentar serviços, planos e facilitar o contato com clientes. O design é responsivo e moderno, priorizando a experiência do usuário e a conversão.

## 🚀 Tecnologias Utilizadas

O projeto foi desenvolvido utilizando as seguintes tecnologias:

*   **HTML5**: Estruturação semântica do conteúdo.
*   **CSS3**: Estilização, layouts (Flexbox/Grid) e animações.
*   **JavaScript**: Funcionalidades interativas e manipulação de DOM.
*   **Materialize CSS**: Framework front-end baseado em Material Design para acelerar o desenvolvimento de componentes.
*   **Google Fonts & Material Icons**: Tipografia e iconografia personalizada.

## 📋 Funcionalidades

- [x] **Design Responsivo**: Adaptado para dispositivos móveis, tablets e desktops.
- [x] **Navegação Dinâmica**: Menu fixo com efeitos de transição.
- [x] **Seção de Serviços**: Apresentação visual das modalidades oferecidas pela academia.
- [x] **Galeria de Imagens/Cards**: Destaques sobre a infraestrutura e diferenciais.
- [x] **Formulário de Contato**: Área integrada para captação de leads e dúvidas.
- [x] **Integração com Mapas**: Localização da unidade para facilitar o acesso.
